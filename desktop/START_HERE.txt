INSTALL
1. Extract this ZIP to a folder.
2. Double-click AETOS-Office-Assistant.exe.
3. Click Set up AETOS Office Assistant. Approve the AETOS Office Assistant localhost certificate if Windows asks.
4. Restart Word if it was already open.
5. In Word, open Add-ins / My Add-ins and select AETOS Office Assistant
   under Developer Add-ins (the exact label varies by Word version).
6. In AETOS Office Assistant, choose Model connection and save your endpoint, model and key.

No Node.js, npm, PowerShell commands or terminal windows are needed to USE it.
The source/build scripts are supplied only for developers.

DAILY USE
Leave “Start automatically when I sign in to Windows” selected during setup.
AETOS Office Assistant then runs in the background with a tray icon beside the clock.
You can also start it from the Start menu: AETOS Office Assistant.
Right-click its tray icon to open Word, change startup, quit or remove setup.
Quitting stops the server and the Word panel will not work until AETOS Office Assistant restarts.

REQUIREMENTS
Windows 10/11 with .NET Framework 4.8 and current Microsoft 365 Word/WebView2.
This executable is for Windows; it is not a macOS installer.
Office.js is fetched from Microsoft's official CDN at runtime, so this does
not make the Word add-in completely offline.

WHAT SETUP DOES
- Copies the executable and manifest under:
  %LOCALAPPDATA%\AETOS Office Assistant\OfficeAssistant
- Registers this add-in for the current user using Office's developer catalog.
- Creates a unique localhost TLS certificate and trusts its public certificate
  in the CURRENT USER certificate store. No shared private key is shipped.
- Protects its saved private certificate with Windows DPAPI for your account.
- Creates a Start menu shortcut and, if selected, a current-user sign-in entry.
- Serves only embedded static assets on https://localhost:38473.
  No public network listener, remote proxy or Windows service is installed.

SETTINGS AND PROVIDERS
Because this launcher uses port 38473 instead of the previous development
port 3000, previously saved model connections are not automatically migrated.
Re-enter them in the new panel. Your provider must permit CORS requests from
https://localhost:38473. Model API keys remain visible and unencrypted in
the panel's local browser storage, as specified in the original PRD.
The native launcher never reads those keys or proxies generation requests.

REMOVAL
Tray icon > Remove AETOS Office Assistant setup removes its Word registration, startup entry,
Start menu shortcut and locally trusted certificate. It leaves the executable
and browser connection settings. Exit the app before deleting its executable.
To remove a saved API key, clear it and save in Model connection before removal.
Existing shared-folder registrations from the earlier manual setup are not
removed automatically.
